# 01 业务需求

## 1. 总体业务闭环

```text
客户看到宣传或收到链接
→ 浏览企业、基地和品种
→ 选择商品薯或种薯
→ 查看当前供应或使用选品助手
→ 提交询价
→ 销售补充需求并报价
→ 客户确认样品、合同与批次
→ 企业备货、检测、分选和包装
→ 创建订单并更新交付节点
→ 客户查询批次和订单
→ 到货签收与复购跟进
```

## 2. 商品薯业务

### 2.1 目标客户

- 俄罗斯批发商和经销商
- 农产品贸易公司
- 水洗和包装企业
- 净菜加工企业
- 餐饮供应链
- 食品加工企业

### 2.2 商品薯分类

- 鲜销
- 水洗
- 净菜加工
- 薯条或其他加工
- 储藏

分类用于展示和选品，不等同于法定商品分类或海关编码。

以上五类均为实际经营范围。佳秀农业自有水洗、分选、包装和冷藏能力；后台需能维护处理能力说明、实拍资料以及每个供应批次可选择的服务。

### 2.3 商品薯询价最小信息

- 品种或“需要推荐”
- 采购用途
- 单薯规格
- 水洗或带土
- 包装要求
- 采购数量及单位
- 交货国家、城市或口岸
- 期望交期
- 联系人和联系方式

### 2.4 商品薯报价要素

- 报价编号和有效期
- 产品、品种和批次
- 规格与允许偏差
- 数量和计量单位
- 单价、币种与价格条件
- 包装方式
- 交付地点和预计交期
- 质量与验收约定
- 检测、检疫和单证范围
- 付款约定由线下合同确认

### 2.5 商品薯关键风险

- 规格描述不一致
- 水洗、带土和包装状态理解不同
- 库存货与新薯混淆
- 图片与实际批次不一致
- 到货损耗和质量验收标准不清晰
- 把参考产量或品种特性误认为批次保证

## 3. 种薯业务

### 3.1 目标客户

- 俄罗斯农场
- 农业合作社
- 种植基地
- 农资和种薯经销商
- 农业贸易企业

### 3.2 种薯询价最小信息

- 品种或“需要推荐”
- 所需繁育级别
- 计划种植国家、地区
- 种植面积及单位
- 土壤类型
- 旱地或水浇地
- 重茬情况
- 预计播种时间
- 目标采收或上市时间
- 所需规格和数量
- 交货地点
- 联系人和联系方式

### 3.3 种薯报价与确认要素

- 品种和繁育级别
- 批次编号
- 种薯规格
- 数量和计量单位
- 当前发芽与储存状态
- 可提供的检测、检疫和质量资料
- 出库和交付时间
- 包装、运输和储存要求
- 品种适用条件与风险提示
- 品种登记、授权或准入资料状态

### 3.4 种薯关键风险

- 繁育级别定义不一致
- 品种名称、登记名称或俄文译名不一致
- 无法证明脱毒、检测或批次来源
- 客户种植环境与推荐品种不匹配
- 将技术建议表述为确定性产量承诺
- 目的国准入、品种登记、植物检疫要求未核验

## 4. 品种与供应批次的区别

### 4.1 品种档案

描述相对稳定的品种信息：

- 名称和别名
- 熟期
- 外观和内在品质
- 植株性状
- 抗病与适应性
- 推荐用途
- 优点和风险
- 种植管理参考

### 4.2 供应批次

描述某一时间可以实际交易的货物：

- 商品薯或种薯
- 基地和年份
- 实际规格
- 可供数量
- 采收、入库或出库时间
- 包装方式
- 批次图片和视频
- 检测及证书文件
- 当前供应状态

品种档案中的产量、薯率和品质数字不得自动作为批次承诺。

## 5. 智能选品规则

### 5.1 商品薯选品输入

- 采购用途
- 上市时间
- 是否长期储藏
- 肉色和薯形要求
- 水洗、净菜或加工要求
- 目标规格

输出 1 至 3 个品种，并展示推荐理由、主要风险和相关供应批次。

### 5.2 种薯选品输入

- 种植区域和无霜期
- 土壤与灌溉条件
- 重茬和病害历史
- 目标采收时间
- 目标销售用途
- 储藏条件
- 管理投入水平

推荐结果必须带有“基于当前填写条件的参考建议，正式采购前需人工复核”的提示。

## 6. 询价与销售跟进

### 6.1 询价来源

- 微信小程序
- 俄语 H5
- 业务人员代客户录入
- 线下展会或电话

### 6.2 询价状态

```text
草稿 → 已提交 → 待分配 → 跟进中 → 已报价
                       ├→ 待补充资料
                       ├→ 暂缓
                       └→ 已关闭
已报价 → 已接受 / 已拒绝 / 已失效
```

关闭或拒绝时应记录原因，用于后续分析。

### 6.3 跟进要求

- 每条询价有负责人。
- 保存联系时间、渠道、纪要和下一步时间。
- 内部备注不得对客户展示。
- 重要字段修改需要保留操作记录。

## 7. 批次资料与验证

批次资料状态：

- 未提交
- 待审核
- 已验证
- 已驳回
- 已过期

“已验证”只表示企业内部已核对上传材料，不应自动表述为政府部门批准、目的国准入或质量保证。

## 8. 订单与交付

建议节点：

```text
合同确认 → 批次锁定 → 分选包装 → 检测检疫
→ 待装车 → 已发运 → 口岸处理 → 运输中 → 已签收
```

每个节点可包含：

- 时间
- 状态
- 中文和俄文说明
- 图片、视频或文件
- 是否对客户可见
- 操作人员

## 9. 合规边界

- 平台展示不等于允许出口或允许进口。
- 商品薯与种薯的准入、检测、检疫和品种要求分别核验。
- 海关编码、证书名称和申报要素由专业人员按实际批次确认。
- 不展示无法证实的“官方认证”“保证高产”“绝对无病害”等表述。
- 用户隐私、联系方式和交易资料实行分级权限。
- 正式上线前准备隐私政策、用户协议和信息收集清单。
