## 2. 待确认事项使用说明

状态定义：

- **待确认**：需要业务方明确选择或提供资料。
- **进行中**：责任人已经开始处理，但尚未完成。
- **暂定**：可按建议方案进入设计，正式上线前仍需确认。
- **已确认**：结论已经进入上方决策表，并同步修改相关文档。

优先级定义：

- **P0**：影响 MVP 范围、数据模型、原型或上线。
- **P1**：不阻塞基础开发，但应在联调或试运营前确认。
- **P2**：可在 MVP 上线后继续完善。

### Q-022 代码仓库与部署资源

已确认：

- 前后端分离，微信小程序、俄语 H5 和管理后台通过版本化 REST API 访问后端。

- 后端代码仓库：`https://github.com/azhang111111/PotatoLink_backend.git`。
- 两个代码仓库均为私有仓库，当前由项目方自行开发，暂不配置外部开发协作者。
- 分支管理先采用轻量方案，保留随团队规模扩展审批和保护规则的能力。
- 代码仓库保留 Docker Compose 配置，包含 PostgreSQL、Redis、MinIO 和测试邮件服务；当前电脑不启动容器，PostgreSQL、Redis 和 MinIO 改用 E 盘宿主机服务并已完成 M3 联调。

- 测试和生产环境的服务器及云服务商。
