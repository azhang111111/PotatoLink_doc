# 02 产品需求文档 PRD

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 产品 | PotatoLink 中俄薯贸 |
| 版本 | MVP 需求草案 v0.1 |
| 状态 | 待业务评审 |
| 业务范围 | 商品薯与种薯 |
| 客户市场 | 俄罗斯为主 |

## 2. 用户问题

### 2.1 采购商

- 不知道该选择哪个品种。
- 无法快速判断当前是否有货。
- 产品、批次和证书资料分散。
- 跨语言沟通中规格和用途容易误解。
- 订单发出后无法及时掌握状态。

### 2.2 销售人员

- 重复发送相同图片、视频和介绍。
- 客户询价缺少规格、数量或交货地点。
- 报价、客户和跟进记录分散。
- 中俄双语资料版本不统一。

### 2.3 管理和质量人员

- 难以了解每个批次对外展示了哪些内容。
- 报告、证书和批次照片缺少审核机制。
- 无法统一查看询价、报价和订单漏斗。

## 3. 核心使用场景

1. 俄罗斯采购商通过分享链接查看产品并提交俄语询价。
2. 国内业务人员通过小程序向客户演示六大品种。
3. 客户不知道选什么品种，通过选品助手获得参考推荐。
4. 销售人员在后台补充需求、生成报价并持续跟进。
5. 客户扫描批次二维码查看产地、规格和验证资料。
6. 订单客户查看备货、检验、装车和运输节点。

## 4. 微信小程序需求

### 4.1 首页

必须包含：

- 品牌及一句话定位
- 商品薯、种薯双入口
- 企业和基地实拍
- 六大品种快捷入口
- 当前供应推荐
- 合作流程
- 联系和询价入口
- 俄语 H5 分享入口

验收标准：用户进入首页后两次点击以内到达任一品种详情或询价页面。

### 4.2 品种列表与详情

筛选项：

- 商品薯适用 / 种薯适用
- 熟期
- 用途
- 储藏能力
- 主要适应条件

详情展示：

- 中俄名称
- 图片和视频
- 品种特征
- 推荐用途
- 优势和风险
- 种植或储存注意事项
- 相关供应批次
- 询价按钮

### 4.3 当前供应

- 商品薯和种薯切换
- 品种、基地、上市时间和状态筛选
- 默认不公开精确价格
- 不公开精确库存，展示供应状态，并可选择展示数量区间
- 批次卡片进入详情和询价

### 4.4 选品助手

- 进入时先选择商品薯或种薯。
- 采用逐题表单，保存用户当前答案。
- 输出推荐品种、理由、风险与供应批次。
- 允许用户修改条件并重新计算。
- 支持携带推荐结果进入询价。

### 4.5 在线询价

- 根据业务类型显示不同字段。
- 支持游客提交；联系人必填，手机或邮箱至少填写一项并进行格式校验，Telegram 等联系方式作为可选字段预留。
- 支持图片和文件附件，限制格式与大小。
- 提交前展示隐私提示。
- 提交成功显示询价编号和后续流程。
- 客户可授权后查询自己提交的询价。
- 支持添加多个品种或规格明细；每条明细只对应一个品种，不支持混合品种包装。
- 根据商品薯正式订单、种薯试种订单、种薯正式订单或样品申请校验默认起订量。
- 起订量不足时允许提交“特殊需求”，但不能自动生成普通报价，需销售人工审核。

### 4.6 批次溯源

- 输入批次码或扫码查询。
- 展示批次基础信息和公开时间线。
- 报告显示文件名称、状态、日期和预览。
- 隐藏内部备注、采购成本和敏感客户信息。
- 无效或未公开批次给出明确提示。

### 4.7 订单查询

- 小程序通过微信身份访问；俄语 H5 通过带有效期的安全链接访问，敏感内容可要求邮箱验证码或独立查询码二次验证。
- 展示订单概要和公开节点。
- 支持查看节点附件。
- 不允许通过连续编号遍历其他客户订单。

## 5. 俄语 H5 需求

第一版功能：

- 俄语首页
- 企业与基地
- 品种列表和详情
- 当前供应
- 选品助手
- 在线询价
- 批次查询
- 订单查询
- 联系方式

要求：

- 不依赖微信登录，允许游客浏览和提交询价。
- 可从消息、邮件、二维码直接打开。
- 俄语文本单独审核，不能将中文界面截图替代俄语页面。
- 日期、数量、重量、币种和联系方式符合目标用户习惯。
- 页面提供语言切换。
- 报价和订单使用限时安全链接；MVP 不建设传统账号密码和找回密码体系。

## 6. 管理后台需求

### 6.1 工作台

- 待跟进询价
- 即将失效报价
- 待审核批次资料
- 进行中订单
- 异常或逾期节点
- 近期供应变化
- 通知发送失败和需要人工处理的提醒

### 6.2 内容管理

- 企业、基地、轮播和合作流程
- 品种档案
- 中文和俄文分别编辑
- 翻译状态：未翻译、待审核、已发布
- 发布与下线

### 6.3 供应批次

- 新建商品薯或种薯批次
- 维护规格、数量和时间
- 上传实拍、报告和证书
- 选择公开字段
- 生成二维码
- 状态变更及操作记录
- 种薯繁育级别由后台字典配置，不在程序中写死
- 六个首发品种均允许创建种薯批次
- 后台维护真实库存、锁定数量和可售数量；前台只读取供应状态及允许公开的数量区间

### 6.4 CRM 与询价

- 客户列表和标签
- 询价分配
- 跟进记录
- 重复客户识别
- 询价状态管理
- Excel 导出列作为后续确认项
- 新询价通过微信通知负责人，超时未处理时升级通知管理人员

### 6.5 报价

- 从询价创建报价
- 中俄双语内容
- 版本和有效期
- 提供客户安全访问链接和中俄双语 PDF 导出
- 接受、拒绝、失效状态
- 默认报价币种为人民币，币种仍保留后台配置能力
- 交付方式至少支持基地自提和协助运输至霍尔果斯口岸
- 明确记录国内段和跨境段分别由哪一方安排
- 口岸、线路和交接地点由后台配置，可随业务增加其他对俄路线
- 每次修改形成新版本，已发送版本保持不可变
- 普通报价由销售发送；低于指导价或达到金额阈值时进入管理审批
- 指导价、金额阈值和审批人员由后台配置

### 6.6 订单

- 从接受的报价创建订单
- 关联客户、批次和合同编号
- 维护订单节点
- 控制节点是否对客户公开
- 上传交付附件
- 从已接受报价创建订单，避免重复录入
- MVP 不做电子签约，支持上传并归档双方签署后的合同文件

### 6.7 权限

建议角色：

- 超级管理员
- 管理人员
- 销售人员
- 运营编辑
- 质量审核人员
- 物流人员
- 只读审计人员

权限至少区分查看、创建、修改、审核、导出和删除。

## 7. 通用非功能需求

### 7.1 安全

- 后台采用可靠身份认证。
- 客户数据按角色和负责人授权。
- 文件下载使用授权地址。
- 记录关键操作日志。
- 防止订单和批次查询被枚举。
- 对上传文件校验类型、大小和风险。

### 7.2 性能

- 移动网络下优先保证首屏和品种列表可用。
- 图片生成缩略图并延迟加载。
- 视频默认不自动播放。
- 供应和内容变更需要合理缓存失效机制。

### 7.3 可用性

- 所有关键状态有文字，不只依赖颜色。
- 表单错误定位到具体字段。
- 俄语长文本不得溢出或遮挡按钮。
- 无数据、加载失败和权限不足均有明确页面。

### 7.4 可追踪性

- 报价保留版本。
- 批次资料保留审核人与审核时间。
- 订单节点保留操作记录。
- 品种关键参数修改需要记录历史。
- 通知需记录渠道、接收人、业务对象、模板版本、发送状态、失败原因和重试结果。

## 8. MVP 验收标准

- 可完整维护六个品种的中俄双语资料。
- 可分别创建商品薯和种薯供应批次。
- 两类客户可使用独立选品和询价流程。
- 销售能收到、分配、跟进询价并创建报价。
- 批次可生成唯一二维码并控制公开内容。
- 可从报价创建订单并更新公开节点。
- 俄语 H5 无需微信即可完成浏览和询价。
- 客户之间无法查看彼此询价和订单。
- 后台关键操作有日志。
- 试运营真实用户能够完成端到端流程。

## 9. MVP 后续候选

- 电子合同
- 自动生成贸易单据草稿

- 行情与供应预警
- 农艺服务和种植档案
- 多供应商平台
- 哈萨克斯坦语言及本地化
