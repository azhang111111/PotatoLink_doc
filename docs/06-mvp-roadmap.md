# 06 MVP 路线图

## 1. 优先级

MVP 实施资源按商品薯约 70%、种薯约 30% 安排。两类业务同时上线，商品薯闭环优先进入开发和试运行；种薯保留独立的需求采集、品种推荐、资料审核和人工复核流程。

### P0：MVP 必须完成

- 中俄双语企业、基地和品种
- 商品薯与种薯供应批次
- 双业务选品助手
- 双业务询价
- 客户和销售跟进
- 报价管理
- 批次文件审核和二维码
- 订单及公开节点
- 微信小程序、俄语 H5、管理后台
- 权限、日志和基础安全

### P1：MVP 后优先增强

- 报价 PDF
- 样品寄送管理
- 询价和订单通知
- 销售数据看板
- 库存预警
- 客户分级
- 常用贸易文件模板

### P2：业务验证后再做

- 物流接口和实时跟踪
- 电子合同
- 行情与价格服务
- 农艺服务档案
- 第三方供应商入驻
- 交易服务费体系
- 哈萨克斯坦本地化

## 2. 实施阶段

| 阶段 | 预计时间 | 交付物 | 退出条件 |
|---|---:|---|---|
| 需求确认 | 2—3 天 | 决策记录、范围和流程 | P0 范围签字确认 |
| 原型与技术方案 | 1 周 | 原型、数据模型、接口草案 | 核心流程评审通过 |
| UI 与工程基础 | 1 周 | 设计规范、三端基础工程 | 可部署测试环境 |
| 商品薯闭环 | 1 周 | 供应、选品、询价、后台跟进 | 一次真实模拟询价完成 |
| 种薯闭环 | 1 周 | 种植需求、推荐、询价 | 人工复核流程可用 |
| 批次与订单 | 1—2 周 | 溯源、二维码、报价、订单节点 | 客户可查真实测试订单 |
| 俄语与联调 | 1 周 | 俄语 H5、权限和端到端联调 | 双语流程通过测试 |
| 试运营 | 1 周 | 内容、测试报告和上线清单 | 真实业务用户验收 |

整体 MVP 目标周期为 6—8 周，需根据团队人数、仓库技术栈和资料准备情况修订。

## 3. 第一批开发任务

代码仓库创建后的执行顺序：

1. 仓库、分支、提交和发布规范。
2. 应用架构、数据库和接口约定。
3. 登录、权限、文件和多语言基础。
4. 企业、基地和品种内容管理。
5. 商品薯和种薯批次管理。
6. 公共首页、品种和供应页面。
7. 商品薯选品与询价。
8. 种薯选品与询价。
9. CRM、跟进和报价。
10. 批次审核、二维码和公开查询。
11. 订单与交付节点。
12. 俄语 H5、测试和部署。

## 4. 里程碑

### M1：内容可展示

三端可以读取统一的企业、基地和六大品种资料。

### M2：询价可闭环

客户提交两类询价，销售在后台处理并创建报价。

### M3：批次可验证

真实供应批次能够审核、发布、扫码和关联报告。

### M4：订单可协同

接受报价后创建订单，客户查看交付节点。

### M5：真实试运营

内部业务人员、2 名商品薯采购商和 1 名种薯采购商完成端到端试用。

## 5. 上线门槛

- 六大品种中文内容完成业务审核。
- 所有对外俄文完成专业复核。
- 至少创建 3 个真实或经明确标记的演示批次。
- 商品薯和种薯各完成一次端到端测试。
- 隐私政策、用户协议和信息收集清单就绪。
- 备份、日志、错误监控和恢复方案通过检查。
- 明确询价响应人员和服务时间。
