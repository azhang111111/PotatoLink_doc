# 11 隐私与合规参考

本页仅作为产品设计和上线检查的法规参考，不代替针对具体业务、部署和数据流的专业法律意见。

## 中国个人信息保护

- [中华人民共和国个人信息保护法（工业和信息化部）](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_515a4b20c12f430eab54bb4f56d89f56.html)
- [中华人民共和国个人信息保护法（中央网信办）](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)

产品重点关注：

- 合法、正当、必要和最小范围收集。
- 明确告知处理目的、方式、种类和保存期限。
- 保存期限以实现目的所需的最短时间为原则。
- 提供查询、更正、删除和撤回同意的处理渠道。
- 委托处理、对外提供或跨境提供个人信息时进行相应评估和安排。
- 个人信息保护影响评估报告和处理记录依法保存。

## 俄罗斯个人数据

- [俄罗斯联邦第 152-FZ 号《个人数据法》官方文本](https://ips.pravo.gov.ru/api/ips/legislation/document?baseid=None&hash=98490812b3409e2a8d78a11ca9010f434ea3d9250a11dbbdb78690cd5551bdd6)

俄语 H5 面向俄罗斯客户时，需要在正式上线前由专业人员根据实际运营主体、服务器位置、数据流和客户类型复核：

- 对俄罗斯公民个人数据处理的适用范围。
- 数据收集和存储本地化要求。
- 向中国或其他地区跨境传输的条件。
- 俄文告知、同意和个人权利处理方式。
- 监管备案或通知义务。

## 当前产品决策

- MVP 只收集 B2B 询价和履约所需的最少联系人信息。
- 不主动收集身份证、护照、人脸、银行卡等非必要敏感信息。
- 数据库和主要文件默认部署在中国境内。
- 俄语 H5 正式公开上线前完成俄罗斯个人数据专项复核。
- 专项复核完成前只进行受控试运营，不扩大公开获客范围。
