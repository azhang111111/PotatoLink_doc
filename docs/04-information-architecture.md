# 04 信息架构

## 1. 微信小程序

建议底部导航：

```text
首页｜品种｜供应｜询价｜我的
```

### 首页

- 品牌和企业定位
- 商品薯、种薯双入口
- 基地实拍
- 六大品种
- 推荐供应
- 服务流程
- 联系方式

### 品种

- 全部品种
- 商品薯适用品种
- 种薯适用品种
- 筛选和搜索
- 品种详情
- 相关供应批次

### 供应

- 商品薯批次
- 种薯批次
- 上市日历
- 批次详情
- 批次询价

### 询价

- 商品薯询价
- 种薯询价
- 选品助手
- 我的询价

### 我的

- 个人和企业信息
- 我的询价
- 我的报价
- 我的订单
- 批次查询
- 联系业务人员
- 隐私政策与协议

## 2. 俄语 H5

建议一级导航：

```text
Главная
Сорта
Наличие
Подбор сорта
Запрос цены
Партия / Заказ
Контакты
```

页面应支持无需登录浏览。询价提交、报价和订单等私有功能使用手机、邮箱或一次性访问凭证，具体认证方式在技术设计阶段确定。

## 3. 管理后台

```text
工作台
├─ 待办事项
├─ 询价漏斗
├─ 报价和订单概况
└─ 批次资料预警

内容中心
├─ 企业信息
├─ 基地信息
├─ 品种档案
├─ 首页配置
└─ 中俄翻译审核

供应中心
├─ 商品薯批次
├─ 种薯批次
├─ 库存变动
├─ 检测与证书
└─ 二维码

客户与销售
├─ 客户
├─ 询价
├─ 跟进记录
├─ 报价
└─ 样品

经营分析
├─ 询价与响应
├─ 报价与转化
├─ 订单与吨数
├─ 品种与批次
├─ 样品转化
├─ 运输异常
├─ 文件到期
└─ 成本与毛利（可关闭）

订单与交付
├─ 订单
├─ 批次锁定
├─ 订单节点
├─ 物流信息
└─ 签收与售后

系统管理
├─ 用户与角色
├─ 字典和配置
├─ 文件管理
├─ 操作日志
└─ 隐私与协议版本
```

## 4. 页面复用原则

- 小程序和 H5 共用产品及业务接口。
- 页面布局可针对微信和浏览器分别优化，不强求像素级一致。
- 管理后台是唯一正式维护品种、供应和翻译内容的入口。
- 分享卡片、二维码和外部链接统一进入公开详情页。
- 客户私有页面不能通过公开链接直接访问。
